PHP И JavaScript

Языки программирования PHP и JavaScript позволяет сделать сайт динамичным,то есть реагирующим на действия пользователя.Например,можно сделать красивую выпадающую менюшку или слайдер.

Виды скриптов

Для этого пишутся скрипты(англ. script -"сценарий")-программы позволяющие реагировать на действия пользователя скрипты бывают двух видов:

  • те,которые выполняются на сервере, а результат их выполнения приходит в браузер к использователю уже в готовом виде.Это скрипты,написанные на языке PHP .На нем пишутся CMS-киPHP системы управления контентом.
  • те,которые выполняються прямов браузере пользователя.Это скрипты,написанные на языке JavaScript.Они чаще всего используется для,того чтобы сделать страницу более удобной и красивой
